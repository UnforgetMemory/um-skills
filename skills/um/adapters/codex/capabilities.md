# Codex 特性能力档案

## task 沙箱子任务
- 子任务运行在独立 sandboxed 环境中, 与主会话隔离。
- 可并行启动多个子任务。
- 可指定 agent 执行; 子任务返回独立结果。
- 适合: 独立实验、批量文件操作、互不依赖的并行工作。

## shell 沙箱执行
- 命令在受限沙箱中运行; 文件系统写操作受约束。
- 支持后台执行 (background) 与结果收集。
- 需要更宽权限时, 通过 CLI 交互流程确认。

## 交互
- 文本确认 (TUI): 无 GUI 按钮卡片。
- 决策类请求需给出编号选项, 用户以文本回复编号。

## 网络
- web_search / web_fetch: 搜索与网页抓取, 结果可直接引用来源 URL。

## 上下文
- 上下文压缩与管理依赖 CLI 内置机制 (auto-compact 等), 具体行为以版本为准。
- 无独立 todo 工具: 长任务计划写在对话/笔记中自行维护。

## 能力边界
- 工具集随 Codex CLI 版本演进: 本档案基于已知工具集, 以实际可用为准。
- 不确定某能力是否存在时, 先探测 (帮助/工具清单), 再询问用户确认。
