# 基础约束（L0 — 所有 skill 引用）

## 元约束
1. 每个结论标记 `Fact` / `Assumption` / `Decision`，禁止猜测
2. 禁止伪造 API/参数；未知能力先查官方文档
3. 指令按字面执行：明确条件（IF 确认 THEN 执行），禁止模糊词（"酌情/可能"）

## 缓存稳定（KV Cache 约束）
1. 指令文本永不含动态值：禁时间戳/随机 ID/会话号/易过期数据
2. 需要时间 → 按「时间与最新语义」获取实时锚点，不进指令前缀
3. 需要版本/路径 → read 项目文件，不写死在指令中
4. 会话内稳定结论（环境识别、档位）只判一次，后续引用
5. 动态频繁的值（时间/版本/价格等）→ 指令与 reference 只存权威获取源（URL/工具），不存值本身；使用前按需获取（防过期值与 KV Cache 失效）

## 时间与「最新」语义（时间锚点）
1. 「最新 / 当前 / 现在 / now」一律指实时时间，不是模型知识截止时间
2. 时间锚点获取优先级：
   1. 实时互联网授时：time.is（如 time.is/Beijing）、国家标准时间·国家授时中心（ntsc.ac.cn）等权威源
   2. 用户本地时钟：环境工具按需获取（如 `Get-Date` / `date`）
   3. 均不可得 → 必须询问用户，禁止猜测或用知识截止时间兜底
3. 锚点以会话记忆保存：会话内首次确认、后续引用；禁止写入长久记忆（`.um.agents/memory/*.local.md`）与指令文本；新会话重新确认，不跨会话沿用

## 防幻觉
1. 规则单一事实来源（core 一份），禁止上下文矛盾指令
2. 大规则不内联 → read 引用（防转述失真）
3. 数据驱动：每个断言带证据（文件:行 / 命令输出）

## 禁止行为总纲
- 自动 commit / push / release（必须人工确认）
- 删除未经确认的文件/测试
- 修改无关模块
- 未经验证宣称完成
- 多 agent 同时改同一文件
