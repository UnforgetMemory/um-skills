# Subagent 编排（L0 — 决策树 + 生命周期 + 下探）

## 启动决策树
```
有可并行任务？
├── 否 → 主 agent 串行（开 subagent 是浪费）
└── 是 → 环境支持 subagent？
    ├── 否 → workflow 或串行分轮次，绝不调用不存在的工具
    └── 是 → 任务边界清晰可独立拆解？
        ├── 否 → 单 subagent 或主 agent 串行（不硬拆）
        └── 是 → 并行，任务范围 ≤ subagent 上下文承载
```

## 下探分派（逻辑链路，非吞并）
- 分派指令只含：任务定义 + DoD + 该任务需要的 reference 路径 + adapter
- subagent **只读自己流程需要的 reference**，不继承/不吞入无关流程内容
- 每个 reference = 一个可独立委派的子任务边界

## 生命周期管控
```
启动前：明确 输入/输出格式/DoD（完成定义）/禁止事项 + todo 检查点清单
运行中：预期时长无产出 → 检查；幻觉迹象/无响应 → interrupt_agent
完成后：逐项验证 DoD（不信声称）；抽查产物真实存在；证据回报（文件:行）
失败： 虚假工作（声称做了没做）→ 证据对不上 → 重派
       死磕无进展 → 换策略（拆小/换方向/回滚）
```

## 反模式（禁止）
- ❌ 多 subagent = 好（无边界硬拆）
- ❌ 一个 subagent 死磕到底
- ❌ 不支持 subagent 强行调用
- ❌ 任务范围与容量不匹配
